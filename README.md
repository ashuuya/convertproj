# ConvertProj GUI

Скачивание видео с YouTube и конвертация любых видео под старые кнопочные телефоны (Itel, BQ и др.) в стильном GUI. GUI прикрутил просто от нечего делать. Произошёл вайб кодинг.

## Возможности

- **Скачивание:** Вставка ссылок, выбор качества (360p–4K), прогресс-бар
- **Нормализация:** VFR→CFR 30 FPS с аппаратным ускорением (NVENC/AMF/QSV/CPU)
- **Конвертация:** Профили для телефонов + редактор профилей (кодек, битрейт, разрешение)
- **Drag & Drop:** Перетаскивание видео в очередь конвертации
- **Тёмная тема:** Автоопределение системной темы + ручное переключение
- **Локализация:** Русский / Английский
- **Обновления:** Проверка версий ffmpeg и yt-dlp, обновление в один клик
- **Portable:** Всё в одной папке, никаких следов в системе и визгов от сикретнета

## Установка

### Для разработки

```bash
pip install -r requirements.txt
```

Положите `yt-dlp.exe` и `ffmpeg.exe`/`ffprobe.exe` в `bin/` (создаётся при первом запуске).

```bash
python main.py
```

### Для использования (скомпилированная версия)

1. Запустите `build/build.bat`
2. Готовая папка — `dist/ConvertProj/`
3. Скопируйте папку куда угодно (флешка, диск) — работает без установки

## Структура проекта

```
convertprojGUI/
├── main.py                      # Точка входа
├── convertproj.py               # Логика конвертации (библиотечный модуль)
├── ytdload.py                   # Логика скачивания (библиотечный модуль)
├── config.json                  # Настройки (создаётся автоматически)
├── profiles_custom.json         # Профили конвертации (создаётся автоматически)
├── requirements.txt
├── gui/
│   ├── app.py                   # Загрузка приложения
│   ├── main_window.py           # Главное окно
│   ├── download_tab.py          # Вкладка скачивания
│   ├── convert_tab.py           # Вкладка конвертации
│   ├── about_dialog.py          # Диалог «О программе»
│   ├── profile_manager.py       # Управление профилями
│   ├── worker.py                # Фоновые задачи (QThread)
│   ├── styles.py                # QSS-стили (светлая + тёмная темы)
│   └── translations.py          # Система локализации (JSON)
├── locales/
│   ├── ru.json                  # Русский язык (исходный)
│   └── en.json                  # Английский язык
├── bin/                         # Бинарники (ffmpeg, yt-dlp) — создаётся при первом запуске
├── build/
│   ├── build.bat                # Одна кнопка → .exe
│   └── ConvertProj.spec         # PyInstaller spec
└── downloads/                   # Видео (создаётся при работе)
    ├── Recode/                  # Скачанные
    └── Recoded/                 # Сконвертированные
```

## Технологии

- Python 3.14+
- PyQt6 6.11.0
- FFmpeg / FFprobe
- yt-dlp
- PyInstaller (сборка)

## Сборка .exe

```bash
cd build
build.bat
```

Результат: `dist/ConvertProj/ConvertProj.exe` (self-contained, portable).
